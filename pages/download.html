Requirements:

  • To play Pre-Fortress 2 you must have Source SDK Base 2013 Multiplayer installed.
  • Pre-Fortress 2 needs to be installed on the same drive as Steam.
  • Before running the game you must right-click Source SDK Base 2013 Multiplayer in your library, click Properties,
    click on Betas, and select "previous2021".






Notice

Your computer may potentially falsely flag Wings as a virus, in the event you receive a block notification, click allow to proceed with the download. Wings is open-source and is forked from "Beans" the installer used by the legacy version of Open Fortress. Wings is an in-development project, click here report a bug.

Post-Installation:

  • You will need to restart Steam in order for the mod to appear in your library.
  • Linux users must put -steam -steam in their launch options (Yes, twice).
  • If presented with two launch options, select the second one with no text.
  • Connect to a server via the Server List or visit our Discord server to start a session.
